# Bitácora de uso de IA

## Proyecto
Simulación de Tenis de Mesa en Python

## Herramienta utilizada
- ChatGPT (OpenAI)

## Actividades apoyadas con IA

### 1. Estructuración del proyecto
Se utilizó IA para proponer una organización modular del proyecto en Python, separando parámetros, física, simulación y visualización.

### 2. Implementación de la simulación
Se solicitó apoyo para comprender la migración de funcionalidades desde MATLAB hacia Python y para organizar las funciones de simulación.

### 3. Visualización
Se utilizó IA para generar ejemplos de visualización 3D con Matplotlib y para integrar la trayectoria de la pelota en gráficos tridimensionales.

### 4. Notebook interactivo
Se utilizó IA para construir el notebook de prueba y validar la ejecución de la simulación desde Jupyter.

### 5. Control de versiones
Se utilizó IA como apoyo para operaciones con Git:
- Creación de ramas.
- Merge entre ramas.
- Resolución de problemas de seguimiento de archivos.
- Creación de commits descriptivos.

### 6. Documentación
Se utilizó IA como apoyo para redactar el README y organizar la documentación del proyecto.

## Reflexión

La IA fue utilizada como herramienta de apoyo para acelerar el desarrollo, comprender errores y mejorar la documentación. Todas las decisiones finales, pruebas, ejecución y validación del proyecto fueron realizadas por los integrantes del equipo.
